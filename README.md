# Richard Ishimwe | Personal Portfolio

## Overview
This repository contains my **personal portfolio website**, developed as a **static frontend project** for the **Advanced Web Design and Development Assignment** at **INES Ruhengeri, Year II Computer Science**.  

The portfolio showcases my **frontend development skills, projects, and problem-solving ability using JavaScript**.

---

## Features

- **Hero Section:** Introduction with name, role, tagline, and profile image.  
- **About Me:** Background, education, and career goal.  
- **Skills Section:** Displayed using badges and flexbox.  
- **Projects Section:** 3 real academic projects with screenshots, descriptions, and GitHub links.  
- **GPA Calculator:** Interactive JavaScript calculator with validation and DOM manipulation.  
- **Downloadable CV:** Allows visitors to download my CV in PDF format.  
- **Contact Section:** Contact form and clickable contact info (email, phone, GitHub).  
- **Responsive Design:** Works on mobile, tablet, and desktop using media queries.  
- **Mobile Menu Toggle:** Fully functional hamburger menu on small screens.  
- **Footer:** Shows my email, phone, and GitHub with clickable links.
